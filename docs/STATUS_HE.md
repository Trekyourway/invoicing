# YOURWAY Invoicing — סטטוס ביצוע (20.11.2026)

## הושלם ונבדק כאן
- אפיון מפורט מקצה לקצה, כולל נתיבי נתונים, שליחת המייל, גיבוי, רו"ח, אבטחה, כשלי תקשורת, ותנאי יציאה לפרודקשן.
- קוד Node.js לממשק נייד, API מאומת, קליטת תשלום, אישור התשלום, הפקת קבלה דרך HYP, וערוץ גיבוי PDF ל-Drive.
- SQL עבור MySQL, שמירת reservation לפני הפקה, איסור retry עיוור אחרי timeout, חסימת קבלות כפולות.
- אינטגרציה אופציונלית לתיקיית Drive לקליטת אסמכתאות, עם חילוץ פרטים באמצעות Gemini כאשר יש מפתח; לעולם לא אישור קבלת כספים על סמך OCR.
- שני GitHub Action workflows: בדיקות על PR/main ללא סודות, וקריאת DEMO ידנית בלבד.
- `npm run check`, `node --check src/admin.js` ו-49 בדיקות מקומיות: עברו. אלה בדיקות מקומיות/מוק בלבד.

## לא בוצע בפועל — שערי NO-GO
- המשתמשת פתחה ריפו ציבורי נפרד `Trekyourway/invoicing`; יש לוודא שהקוד וה-CI הופעלו בו.
- לא נוצר/הותקן Hostinger Node.js app, לא הוגדר MySQL חי ולא הורצה `schema.sql` על Hostinger.
- לא בוצעה קריאת דמו אמיתית למפתח HYP; פורמט payment codes/שדות ספק טרם אושר מעשית.
- לא נשלח מייל דמו, ולא התקבל PDF חתום לתוך Drive במסגרת בדיקה חיה.
- HYP API Production דורש תכנית מתאימה; הודעת בעיית חיוב בכרטיס הופיעה בחשבון. לא אומתה הסדרת החיוב או קבלת production key.
- נדרש חיבור Google OAuth או הפעלת גיבוי EasyCount מובנה; חיבור ChatGPT Drive לבדו לא מספק הרשאה לשרת Hostinger.
- בדיקות DB transactions ומקרי התאוששות על MySQL חי עדיין לא בוצעו.
- לא אומתו הגדרות עוסק פטור, המספור והנמען/נושא הדוא"ל אצל ספק המסמכים על מסמך אמיתי.
