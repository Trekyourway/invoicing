# YOURWAY | דרישות תשלום וקבלות

Canonical skill: [skills/yourway-receipts/SKILL.md](../../../skills/yourway-receipts/SKILL.md). Read and apply it in full.

Owner policy (26 Nov 2026):
- HYP may issue **קבלה only** for confirmed received money (type 400).
- **דרישת תשלום** is created outside HYP from [the existing reusable template](../../../templates/yourway-payment-request.html), then printed/saved as PDF and sent only on owner's instruction.
- Never use HYP to issue a transaction invoice, tax invoice, tax-invoice receipt or proforma demand. Historical documents are retained for audit; their active workflows were retired.
- Never confuse a payment demand with an accounting receipt or count an unpaid demand as income.
- Check legal payee, amount, payment status, duplicate receipts, client notification and the verified private ledger state before reporting success.
- Never add real customer data or bank details to a public GitHub file.
